# astrbot_plugin_tomato_obfuscate · 番茄图片混淆

一个 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 插件，基于 **Gilbert 空间填充曲线 + 黄金比例偏移** 实现图片像素混淆与解混淆。支持指令、关键词、LLM 智能调用三种触发方式。

> 算法移植自 [小番茄图片混淆](https://xfqtphx.netlify.app/) 的 JavaScript 版本，使用 Pillow + numpy 加速。

---

## ✨ 功能特性

- 🎨 **像素级混淆**：使用广义希尔伯特曲线（Gilbert Curve）将二维像素按一维曲线顺序重排，再整体循环移位黄金分割比 `(√5-1)/2` 步。
- 🔁 **无损可逆**：解混淆是混淆的逆运算，可完整还原原图（除 JPEG 压缩损失外）。
- 🧱 **抗压缩**：曲线保持空间相关性，混淆图即使被 JPEG 压缩，解混淆后仍能保留色彩与轮廓。
- 🤖 **三种触发方式**：
  1. **指令**：`/混淆`、`/解混淆`
  2. **关键词**：发送或引用图片 + 文本中包含"混淆/打乱/还原/解密"等关键词
  3. **LLM 工具**：开启后，LLM 可在自然语言对话中自动识别意图并调用工具
- 🖼 **多图批处理**：一条消息里有多张图片时依次处理。
- 🔗 **引用图片支持**：支持直接发送图片，也支持引用一条含图片的消息（napcat/QQ 通过 `get_msg` API 主动获取被引用图片）。
- 📦 **PNG 无损混淆图**：混淆图以 PNG 格式保存（无损），确保解混淆时能完美还原；解混淆结果图用 JPEG（展示用，体积小）。
- ⚙️ **可配置**：JPEG 质量、关键词、最大像素、是否启用 LLM 工具等均可通过 WebUI 配置。

## 📦 安装

将本插件目录放入 AstrBot 的 `data/plugins/` 下，并在 WebUI 插件管理页点击「重载插件」即可。

依赖（AstrBot 会自动通过 `requirements.txt` 安装）：

- `Pillow>=9.0.0`
- `numpy>=1.20.0`

## 🚀 使用方法

### 方式一：指令

直接发送指令即可处理同一条消息中附带的图片：

```
/混淆
/解混淆
```

示例：
```
[图片] /混淆
[图片] /解混淆
```

### 方式二：关键词

发送或引用一张图片，附带包含相关关键词的文字即可触发，无需 `/` 前缀：

- **混淆**：`混淆`、`打乱`、`加密图片`、`加密图`、`打乱图片`、`混淆图片`、`搅乱`
- **解混淆**：`解混淆`、`还原`、`解密图片`、`解密图`、`解开混淆`、`还原图片`、`解开`

示例：
```
[图片] 帮我把这张图打乱
[引用图片] 还原一下
```

关键词可在 WebUI 配置中自定义，用 `|` 分隔。

### 方式三：LLM 智能调用

在 WebUI 配置中保持「启用 LLM 工具调用」开启，然后直接用自然语言对话：

```
用户：[图片] 这张图帮我加密一下像素
助手：已为你混淆这张图片：[混淆后的图片]
```

```
用户：[图片] 把这张图还原回来
助手：已为你解混淆：[还原后的图片]
```

LLM 会根据语义自动判断调用 `tomato_obfuscate_image` 还是 `tomato_deobfuscate_image`，无需用户记忆指令。

## ⚙️ 配置项

在 AstrBot WebUI 的插件管理页可直接配置以下项：

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `jpeg_quality` | float | `0.95` | 输出 JPEG 质量，取值 `0.0~1.0`。越高还原度越好。 |
| `enable_llm_tool` | bool | `true` | 是否启用 LLM 工具调用。 |
| `obfuscate_keywords` | string | `混淆\|打乱\|加密图片\|加密图\|打乱图片\|混淆图片\|搅乱` | 混淆触发关键词，用 `\|` 分隔。 |
| `deobfuscate_keywords` | string | `解混淆\|还原\|解密图片\|解密图\|解开混淆\|还原图片\|解开` | 解混淆触发关键词，用 `\|` 分隔。 |
| `max_image_pixels` | int | `2073600` | 图片宽×高的上限（约 1920×1080），超过会等比缩小。 |

## 🧠 算法原理（简述）

1. **生成 Gilbert 曲线**：对 `width × height` 的矩形生成一条覆盖所有像素的广义希尔伯特曲线，得到坐标序列 `curve[i] = (x, y)`。
2. **计算偏移量**：`offset = round((√5 - 1) / 2 × width × height)`（黄金分割比）。
3. **混淆**：把曲线上第 `i` 个位置的像素移到第 `(i + offset) % total` 个位置。
4. **解混淆**：反向移位，把第 `(i + offset) % total` 个位置的像素移回第 `i` 个位置。

由于 Gilbert 曲线在二维空间中是连续的，曲线上相邻的像素在二维中也大概率相邻，因此混淆后的图片相邻像素颜色仍接近，能很好地抵抗 JPEG 压缩。

> ⚠️ 本插件仅供技术交流与图像处理学习使用，**不适合作为真正的加密手段**——算法公开、密钥空间小、已知明文即可破解。

## ❓ 常见问题

**Q：解混淆后图片没有完全还原？**
A：自 v1.0.0 起，混淆图以 PNG 无损格式保存，只要图片在传输过程中未被平台二次压缩/转码，解混淆后可**字节级完美还原**。如果仍无法还原，通常是 QQ/平台压缩导致图片尺寸变化——请确保混淆图在发送和引用时保持原始尺寸（不要被平台缩放）。

**Q：引用图片没有触发处理？**
A：本插件已适配 napcat (aiocqhttp/OneBot v11) 的引用消息，会通过 `get_msg` API 主动获取被引用消息中的图片。如果仍不生效：① 确认平台是 aiocqhttp；② 尝试直接发送图片而非引用；③ 检查 napcat 是否有 `get_msg` API 权限。

**Q：大图处理很慢？**
A：调小 `max_image_pixels`（如 `1000000`）让插件自动等比缩小图片。

**Q：LLM 没有自动调用工具？**
A：请确认：① 配置中 `enable_llm_tool` 为 `true`；② 当前会话使用的 LLM 提供商支持 Function Calling；③ 对话中确实包含图片。
